Chapter 05 Privacy by Design
===

● Point 1: Default Privacy
Privacy is built in from the start.
It is not added later.
The system remains secure.
Legal risks are reduced.

● Point 2: End-to-End Encryption
Data is encrypted at every stage.
Data theft becomes difficult.
Misuse is prevented.
Users feel safe.

● Point 3: User Consent
User consent is central to the system.
Control stays with the user.
Data usage is transparent.
Trust is maintained.
